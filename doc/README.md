需求清单1

## **一、需求1：成品入库时自动扣减半成品库存**

1、【小程序端】成品入库-界面修改

2、【pc网页端】首页-库位-新增入库 界面修改

3、【小程序端】成品入库-半成品选择的逻辑增加

系统根据用户选择的对应半成品，查询相应库位是否有充足库存，若是，则分别在对应库位执行出库，生成出库记录并扣减相应库存；若否，则报错并提示用户；

4、【pc网页端】出入库管理-查看半成品：
入库成功后，生成的“半成品使用记录”，将原来的 JSON 存储结构改为结构化表

## 二、需求2：支持按“件数”进行出入库管理

1、【小程序端】成品入库界面修改

2、【小程序端】成品出库界面修改

出库支持散件优先出库或整版优先出库：库位分为左右两列，2列各有多个版位，每个版位放多个件，散件就是版位的件数未满的，整版就是版位的件数已满的。如果选择散件优先出库，则从库位中是散件的版位出，如果选择整版优先出库则从库位中是整版的版位出。
如果是选择的出库顺序是左边先出、散件优先，左边没有散件，右边有散件，那先出左边的整版还是先找到右边的散件先出，再出左边的整版。
选了散件优先，优先散件。

3、【pc网页端】首页-库位
3-1、新增出库


3-2、库存页面展示“板+件”格式

4、【pc网页端】出入库管理


需求清单2

### 一、产品信息增加“化验信息显示”

1、【pc网页端】首页-库位-产品信息

2、【小程序端】库存查询-查看详情

3、具体展示内容如下：

数据来源：取该产品采样日期为该入库日期的最新一条化验结果。

展示内容：色值、还原糖分、干燥失重、电导灰分、蔗糖分、不溶于水杂质、pH值、化验员名称、版本、是否合格、合格标准

### 二、增加退货入库（其他入库）功能

1、【pc网页端】首页-库位-产品详情

2、【小程序端】成品入库

3、退货入库功能说明

功能和入库功能一样，但唯一不同点就是：正常入库会减少半成品库存，而退货入库不会减少半成品库存。

## 三、增加“调拨”功能

1、【pc网页端】首页-库位-产品详情

2、【小程序端】库存查询页面

3、功能说明

调拨是从1个仓库调到另外一个仓库，需要选择仓库、并输入调拨数量，调拨从1个仓库出库时按照系统出库规则进行，再入到另外仓库时按照入库规则处理。

## 四、增加“产品库存列表”功能

1、【pc网页端】在左边菜单增加“产品库存”，点击进入看到产品（成品/半成品）的现有库存。

2、【小程序端】首页

3、功能说明

该库存数据及重量统计是所有库位的产品库存总和。
