# 生产日报按车间记录制表人

## 业务规则

每个车间（含全厂汇总分区）独立记录制表人。保存车间内容成功后，由后端使用当前登录用户的姓名更新该车间 `preparedByName`；客户端不能指定该姓名。切换账号后，保存哪个车间就更新哪个车间。其他车间不受影响。姓名代表该车间最近一次成功保存的填写人，不是固定人员配置。

只查看、保存整表制表日期、单独提交或整表提交，都不改变车间制表人。提交前若安卓客户端有未保存内容，会先保存已修改的车间，因此这些车间记录当前填写人。乐观锁冲突或事务失败不会改变已保存的制表人。

网页各车间 TAB、安卓车间页及录入分组底部均靠右显示制表人；Excel 在各车间区域末尾靠右显示。整表顶部不再展示或编辑统一制表人，网页历史列表也不再展示该整表字段。

历史整表姓名及 `updatedByName` 无法可靠还原原始车间填写人，故不做猜测性回填；未记录的车间显示“未记录”，下次实际保存后自动记录。旧整表字段暂保留以兼容旧客户端和旧 Excel 导入，但不作为车间制表人的回退值。新格式 Excel 导入时，各车间姓名按实际确认导入的当前登录用户记录，不信任文件中的署名。
