# 标签打印助手常见问题排查

## 1. GUI 显示服务异常

请优先检查：

1. 当前电脑是否已有其他程序占用 `9527`
2. 安全软件是否拦截了本地服务启动
3. 是否启动了旧版本打印助手但未完全退出

建议处理：

1. 先退出旧版本打印助手
2. 重新启动本次交付的 GUI 工具
3. 如果仍失败，打开日志目录并反馈日志

## 2. Web 端提示未检测到打印助手

请检查：

1. 本地打印助手是否已启动
2. GUI 是否显示“运行中”
3. 本地地址是否为 `127.0.0.1:9527`
4. 浏览器是否能访问 `http://127.0.0.1:9527/health`

## 3. 打印机列表为空

这通常表示 Windows 当前没有识别到可用打印机。请检查：

1. 打印机驱动是否已安装
2. 打印机是否在线
3. Windows 控制面板中是否能看到目标打印机

## 4. 测试打印失败

请检查：

1. 是否已正确选择默认打印机
2. 打印机是否缺纸、离线或报错
3. 当前打印驱动是否支持本机环境

## 5. 默认打印机保存后未生效

配置默认保存在：

```text
%USERPROFILE%\.laibin-printer-assistant\config.json
```

请检查：

1. 当前 Windows 账号是否有写入用户目录权限
2. 安全软件是否阻止程序写入配置文件

## 6. 找不到日志

日志默认保存在：

```text
%USERPROFILE%\.laibin-printer-assistant\logs\printer-assistant.log
```

如果 GUI 中打开日志失败，请手动进入上述目录查看。

## 7. 关闭窗口后程序似乎没有退出

这是预期行为。关闭主窗口只会最小化到系统托盘，方便 Web 端继续调用。

如需彻底退出：

1. 找到右下角系统托盘图标
2. 右键选择退出

## 8. 开机自启没有生效

请检查：

1. 是否已在 GUI 中勾选开机自启并保存
2. 当前账号是否允许写入开机启动项
3. 是否使用的是打包版或稳定目录中的便携版

如果是开发环境临时启动，开机自启不一定稳定，建议以交付目录中的正式产物验证。
