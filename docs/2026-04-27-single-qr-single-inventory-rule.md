# 2026-04-27 单二维码单库存占位规则收口

## 规则

- 一个二维码 = 一个库存占位 = 一条 `inventory` 记录。
- 整板入库：`quantity=1`，`pieces=0`。
- 散件入库：`quantity=1`，`pieces=实际件数`，语义为“占 1 板位”。
- 单个二维码只允许两种最小任务：
  - `1 板`
  - `少于每板件数的散件`
- `3板10件` 必须拆成 `3` 条整板记录和 `1` 条散件记录，不能让单码承载超过一板散件。

## 后端调整

- 新增 `PalletInventoryOccupancyRule`，统一校验单二维码数量与散件拆分规则。
- 取消散件“补旧散件行”逻辑，不再跨批次凑板。
- 散件入库先标准化拆分为“若干整板 + 一条散件”。
- 指定位置入库允许散件，散件与整板一样可以落到 `库位 + 左右 + 排 + 层`。
- 二维码绑定、半成品绑定、二维码入库统一校验“单二维码最小任务”。
- 入库记录和半成品入库记录的 `quantity/totalWeight` 改为按实际入库结果回写。

## 前端调整

- 入库确认和半成品绑定的“件”数量上限改为“严格小于每板件数”。
- 库存展示中，散件改为：
  - `10件，占1板位`
- 不再展示容易误解的：
  - `1板 / 10件`

## 验证

- `mvn -q -Dtest=PalletInventoryOccupancyRuleTest test`
