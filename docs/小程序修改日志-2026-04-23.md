# 小程序修改日志

版本：2.1  
日期：2026-04-23  
上次版本：小程序 2.0 版本升级

## 一、版本定位

本次更新是在小程序 2.0 主体升级后的收口版本，重点不是重做整体架构，而是在现有“扫码作业 + 任务闭环 + 查询追溯”基础上补齐现场使用细节。

本轮目标：

- 强化查询中心能力
- 补齐化验录入入口
- 优化帮助中心阅读体验
- 修复扫码异常提示问题
- 降低真机调试和发布包体风险

## 二、主要更新

### 1. 查询中心能力增强

- 化验查询页新增“新增化验”入口
- 支持按产品或批量化验组录入化验数据
- 新增字段与 Web 端化验管理页保持一致：
  - 化验产品名称
  - 采样日期
  - 色值
  - 还原糖分
  - 干燥失重
  - 电导灰分
  - 蔗糖分
  - 不溶于水杂质
  - pH 值
- 提交时复用后端 `/api/assay/import` 接口，不新增独立后端链路

### 2. 帮助中心改版收口

- 帮助中心新增首页
- 首页展示数字仓储小程序海报
- 首页只保留：
  - 海报
  - 数字仓储小程序介绍
  - 本章说明
- 首页移除：
  - 操作步骤
  - 现场注意事项
  - 常见问题
  - 立即操作
- 其他章节仍保留完整说明、注意事项、常见问题和快捷操作入口
- 目录和章节标题固定在可视区域内，正文内容独立滚动，阅读时不再丢失当前位置

### 3. 扫码页异常处理修复

- 修复扫码页扫到部分非预期状态二维码时报错的问题
- 修复已创建任务二维码触发 `Can't find variable: getTaskList` 的问题
- 补齐待处理任务校验逻辑
- 错误提示改为用户可理解文案，避免直接暴露运行时异常

### 4. 登录页与说明文案优化

- 登录页说明文案调整为公司内部使用口径
- 帮助中心各章节说明文案进一步收口，减少现场用户理解成本
- 固定产品二维码相关提示更明确，避免现场重复绑定或重复创建任务

### 5. 包体与真机调试收口

- 移除小程序目录下的开发上下文资料，避免参与真机调试打包
- 排查并确认主要包体来源为图片资源
- 当前真机调试包体已恢复到可正常编译状态
- 后续如继续增长，优先压缩或远程化以下资源：
  - `assets/poster.png`
  - `assets/logo.png`

## 三、体验变化

### 现场人员

- 进入帮助中心后，首页更像正式说明页，不再堆叠过多内容
- 阅读具体章节时，目录和标题始终可见，切换章节更稳定
- 扫码异常时能看到明确提示，不再出现开发报错
- 化验人员可以在小程序端直接补录化验数据

### 管理人员

- 小程序查询能力更完整
- 化验录入与 Web 端口径一致
- 固定产品二维码现场说明更清楚
- 小程序包体风险降低，真机调试更稳定

## 六、验证建议

建议本轮至少验证以下场景：

1. 真机调试可以正常编译，不再出现 2MB source size 超限
2. 帮助中心首页只显示海报、介绍和本章说明
3. 帮助中心切换章节时目录和标题保持固定
4. 扫码已存在待处理任务的二维码时，不再出现 `getTaskList` 运行时错误
5. 化验查询页有权限账号可打开新增弹层并提交化验
6. 无权限账号不应看到或不能使用对应录入入口
