# 仓库平面图库存明细修复

## 问题

仓库平面图右侧“产品明细”使用库位库存分页接口按产品汇总。整板和散件属于不同二维码、不同库存占位时，汇总后如果存在散件 `pieces > 0`，前端沿用了单个库存占位的展示规则，只显示为“35件，占1板位”，导致同产品下的整板数量没有展示出来。

## 修复

1. `/inventory/qualified-inventory/{warehouseId}/page` 保持按产品汇总，不展示单个二维码明细。
2. 汇总时整板数只统计整板库存，散件数单独汇总，避免把散件的占位板数当作整板库存。
3. 平面图右侧“产品明细”使用产品汇总展示，数量显示为“1板35件”，并展示最早生产日期。

## 口径

继续遵循“一条 inventory 记录 = 一个二维码 = 一个库存占位”的规则。弹窗中的单个库存占位明细仍按整板显示为“1板”、散件显示为“35件，占1板位”；右侧产品汇总按产品合并显示为“1板35件”。
