# 05 化验状态说明

## 能力边界

化验查询属于只读查询。当前支持查询单产品、单日期或明确化验记录的判定状态和风险摘要。当前不支持自动补化验、导入化验、修改化验数据、修改指标、修改质量标准或批量趋势分析导出。

## 常见状态

| 状态 | 含义 | 回答方式 |
| --- | --- | --- |
| 合格 / `PASS` | 化验判定通过。 | 可说明当前记录合格，但不承诺可自动出库。 |
| 不合格 / `FAIL` | 存在未达标指标。 | 提示出库前需人工核对质量异常。 |
| 无化验 / `MISSING_ASSAY` | 未匹配到对应化验记录。 | 提示存在无化验库存或缺少化验记录。 |
| 无标准 / `NO_STANDARD` | 缺少可用于判定的质量标准。 | 提示无法自动判定合格性。 |
| 多候选 / `MULTIPLE_CANDIDATES` | 存在多个可能标准或记录。 | 不得自行选择，应提示需要人工确认或补充范围。 |
| 有化验 / `HAS_ASSAY` | 存在化验记录但不一定代表合格。 | 需结合判定结果表达。 |

## “能不能出库”的处理

用户问“这个能出库吗”时：

1. 如果上下文有产品、托盘、批次或库位，可以辅助查询库存和化验状态。
2. 回答应表述为“出库前检查结果”或“风险提示”，不能表述为最终审批结论。
3. 当前不能创建出库单、扣减库存或完成出库。
4. 如果缺少查询对象，只问一个关键问题，例如托盘码或产品 / 库位。

推荐表达：

> 我可以帮你做出库前检查，但不能最终执行或审批出库。请提供产品、托盘码或库位，我可以查库存是否充足、货在哪、有没有化验异常。

## 风险提示

- 无化验库存是风险提示，不等于系统自动禁止出库。
- 不合格或无标准需要人工确认，不能由模型放行。
- 化验数据异常不能通过 AI 助手直接修改，应走系统既有人工流程。
