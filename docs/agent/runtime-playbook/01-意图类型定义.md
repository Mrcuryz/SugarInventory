# 01 意图类型定义

每轮对话先生成业务级、安全、可审计的意图快照。快照描述路由结果，不记录模型推理过程。

## 结构化字段

```json
{
  "intent_type": "...",
  "intent_subtype": "...",
  "business_domain": "...",
  "business_objects": {
    "product": null,
    "warehouse": null,
    "pallet": null,
    "batch": null,
    "date_range": null,
    "inspection_status": null
  },
  "missing_slots": [],
  "support_status": "supported | partially_supported | unsupported | ambiguous",
  "next_action": "answer_directly | ask_clarification | call_tool | explain_unsupported | create_preview_placeholder",
  "planned_tools": []
}
```

## 类型定义

| intent_type | 定义 | 常见问法 | next_action | 工具策略 |
| --- | --- | --- | --- | --- |
| `smalltalk` | 问候、简单寒暄 | 你好、您好 | `answer_directly` | 不调用工具 |
| `capability` | 询问助手身份或能力 | 你是什么、你能干嘛、你现在能做什么、你支持什么、这个助手有什么用 | `answer_directly` | 不调用工具，不要求补业务参数 |
| `business_faq` | 业务术语、流程、规则说明，不查询实时事实 | 无化验是什么意思、库位占用率怎么理解 | `answer_directly` | 不调用实时工具，除非用户同时发起数据查询 |
| `data_query` | 实时数据查询 | 黄冰糖库存、1号库位有什么、托盘 Pxxx 状态、今天有没有化验 | `call_tool` 或 `ask_clarification` | 只调用已注册只读工具 |
| `report_analysis` | 报表、趋势、统计或分析 | 最近30天化验趋势、导出报表、统计无化验库存 | `call_tool` 或 `explain_unsupported` | 只支持受控库存分布；批量化验趋势和导出当前不支持 |
| `write_operation` | 会修改业务数据的真实操作 | 帮我出库、入库、调拨、改库存、新增产品、修改指标 | `explain_unsupported` | 当前不执行写入，可给只读替代检查路径 |
| `unsupported` | 仓储相关但当前系统或工具未覆盖 | 导出 Excel、做任意 SQL、批量质量分析 | `explain_unsupported` | 不编造结果，说明缺口和可替代查询 |
| `ambiguous` | 业务方向明确但缺最关键查询范围 | 查一下库存、查一下化验 | `ask_clarification` | 只问一个关键问题，给一到两个示例 |
| `unrelated` | 非仓储问题 | 天气、股票、写诗、电影 | `explain_unsupported` | 简短引导回仓储能力 |
| `feedback` | 用户反馈回答质量或数据问题 | 数据不对、没解决、答非所问、展示问题 | `answer_directly` | 记录 Review 线索，必要时引导重新只读查询 |

## 判定优先级

1. 敏感凭据和越权请求优先判为 `unsupported`。
2. 用户反馈优先判为 `feedback`。
3. 问候和能力询问优先于业务缺参。
4. 写操作优先于数据查询；例如“帮我出库”不是托盘查询缺码。
5. 数据查询再判断是否缺关键范围。
6. 无关内容简短拒绝并引导回库存、库位、托盘、化验能力。
