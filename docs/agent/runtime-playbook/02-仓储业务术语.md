# 02 仓储业务术语

| 术语 | 说明 | Agent 处理要点 |
| --- | --- | --- |
| 产品 | 仓储库存的业务品种或 SKU。用户可能只说大类，也可能说具体规格。 | 同名多规格必须消歧，不得猜产品内部 ID。 |
| 规格 | 产品的包装、重量、件数、板件换算等具体区别，例如袋装、箱装、每板件数。 | 回答库存时尽量用业务展示口径，不混淆不同规格的板数。 |
| 批次 | 与生产、入库或追溯相关的一组库存标识。可能和生产日期相关，但不等同于生产日期。 | 用户给出批次时作为过滤或上下文；没有明确批次不得猜测。 |
| 托盘 | 承载具体库存和流转记录的对象，通常通过托盘码或二维码识别。 | 托盘查询需要明确托盘码；没有托盘码时只问托盘码。 |
| 库位 | 库存存放位置。用户可能说“1号库位”“1号库”“库位1”。 | 必须通过库位解析确认，不能把数字当 `warehouseId`。 |
| 库存 | 当前在库数量及相关产品、库位、托盘、日期、状态信息。 | 实时库存必须通过只读工具查询。 |
| 可用库存 | 可用于业务参考的当前库存。具体是否能出库还取决于业务制度、化验、权限和人工审批。 | 当前只能辅助检查，不做最终放行或审批。 |
| 无化验库存 | 库存存在但系统没有匹配到对应化验记录或判定结果。 | 作为风险提示，不等于系统自动禁止出库。 |
| 化验状态 | 产品质量检测和判定状态，如合格、不合格、无化验、无标准、多候选。 | 只能查询，不能补化验、改指标或修改标准。 |
| 入库 | 将库存加入系统或进入库位的写操作。 | 当前不执行，只能做入库前只读核对。 |
| 出库 | 扣减或移出库存的写操作。 | 当前不执行，只能做出库前库存、库位、托盘、化验检查。 |
| 调拨 / 移库 | 将库存或托盘从一个库位移动到另一个库位的写操作。 | 当前不执行，只能查询源库位、目标库位、托盘和容量信息。 |
| 库位容量 | 库位可容纳托盘或库存的容量配置。 | 用户问“还有多少容量、满了吗、占用率”时查询库位状态。 |
| 占用率 | 已占用容量占最大容量的比例。 | 不等于该库位产品清单；“有什么”应查库存分布。 |

术语解释只提供业务含义，不代表实时事实。涉及当前数量、位置、状态、化验结果时必须调用只读工具。
