# 06 工具能力说明

工具能力以 `docs/agent/tool-capability-registry.yaml` 和运行时代码中的 `TOOL_CAPABILITY_REGISTRY` 为准。本文提供业务侧使用说明，不替代工具 schema。

## 当前只读工具

| 工具 | 业务名称 | 适合回答 | 不适合回答 |
| --- | --- | --- | --- |
| `resolve_products` | 产品解析 | 用户输入产品名后确认候选产品或范围 | 直接回答库存数量；替用户选内部 ID |
| `resolve_warehouses` | 库位解析 | 解析“1号库位”“库位1”等自然语言库位 | 直接回答库存或容量；把数字当内部 ID |
| `get_inventory_overview` | 单产品库存概览 | 已确认产品当前库存、板件、总件数、重量摘要 | 全部产品、按库位聚合、写操作 |
| `get_inventory_distribution` | 库存分布查询 | 产品在哪些库位；某库位有什么；受控聚合分布 | 任意明细下钻、报表导出、库存修改 |
| `get_warehouse_status` | 库位状态查询 | 已确认库位的容量、占用、状态 | 某库位所有产品清单 |
| `get_pallet_status` | 托盘状态查询 | 明确托盘码的产品、位置、数量、化验、流转摘要 | 作废、恢复、确认任务、出库托盘 |
| `get_assay_status` | 化验状态查询 | 已确认产品和日期或明确化验记录的判定状态 | 批量趋势、导入、更新、删除化验、修改指标 |
| `query_assay_records` | 化验记录范围查询 | 今天有哪些化验记录；某产品最近 N 天化验记录；最近一次化验 | 趋势分析、报告详情、报表导出、化验写入 |
| `query_assay_abnormalities` | 化验质量异常聚合查询 | 最近有哪些化验异常；哪些产品化验不合格；哪些记录无标准；指标越界统计 | 无化验产品、趋势分析、报表导出、化验写入 |
| `query_products_without_recent_assay` | 缺化验在库产品查询 | 今天哪些产品没有化验；最近 N 天哪些在库产品没有化验；某库位有哪些库存缺化验 | 不合格统计、无标准记录、化验写入 |
| `query_assay_standard_coverage` | 质量标准覆盖查询 | 哪些在库产品没有质量标准；哪些产品未绑定有效标准 | 修改质量标准；标准最近未使用；化验记录无标准统计 |
| `query_qr_code_lifecycle` | 二维码 / 托盘生命周期查询 | 明确托盘码从打印、绑定、入库、流转到当前状态的安全摘要 | 作废、恢复、重新绑定、猜测不存在的码 |
| `query_printed_not_inbound_codes` | 已打印未入库二维码查询 | 哪些码打印了但没入库；打印批次未入库数量和完成率 | 修改标签状态、执行入库、没有打印来源时的推断 |
| `query_pallet_anomalies` | 托盘生命周期异常查询 | 状态与库存不一致、重复入库、无入库出库、产品绑定不一致 | 自动修复；没有扫描日志时断言作废码被扫描 |
| `query_pallet_flow_records` | 托盘流转记录查询 | 按托盘码、产品、库位、日期和事件类型查看分页流转记录 | 补写流转、修改记录、把内部 flow ID 当作用户证据 |
| `query_qr_batch_inbound_completion` | 二维码批次入库完成率查询 | 指定批次、订单、产品或日期范围的打印/入库完成率 | 没有统计范围时猜测；补入库、重打或回收标签 |

## 常用链路

- 产品库存：`resolve_products -> get_inventory_overview`
- 产品库存分布：`resolve_products -> get_inventory_distribution`
- 库位库存内容：`resolve_warehouses -> get_inventory_distribution`
- 库位容量 / 状态：`resolve_warehouses -> get_warehouse_status`
- 托盘状态：`get_pallet_status`
- 化验状态：`resolve_products -> get_assay_status`，或上下文已有唯一产品时直接 `get_assay_status`
- 化验记录范围：`resolve_products -> query_assay_records`，或明确“全部产品 / 今天有哪些化验记录”时直接 `query_assay_records`
- 化验异常聚合：`resolve_products -> query_assay_abnormalities`，或全局异常问题直接 `query_assay_abnormalities`
- 缺化验在库产品：`resolve_products -> query_products_without_recent_assay`、`resolve_warehouses -> query_products_without_recent_assay`，或全局缺化验问题直接 `query_products_without_recent_assay`
- 质量标准覆盖：`resolve_products -> query_assay_standard_coverage`，或全局“哪些在库产品没有质量标准”直接 `query_assay_standard_coverage`
- 二维码生命周期：`query_qr_code_lifecycle`（必须先有明确托盘码）
- 已打印未入库：`resolve_products -> query_printed_not_inbound_codes`，或全部产品直接 `query_printed_not_inbound_codes`
- 托盘异常：`resolve_products / resolve_warehouses -> query_pallet_anomalies`，或全局异常直接 `query_pallet_anomalies`
- 托盘流转记录：`resolve_products / resolve_warehouses -> query_pallet_flow_records`，或明确托盘码直接 `query_pallet_flow_records`
- 批次入库完成率：`query_qr_batch_inbound_completion`；必须提供批次、订单、产品或日期范围之一

Resolver 只负责确认实体，不能作为最终答案。解析成功后应继续主查询；解析多候选时必须反问；未找到时不得编造。

## 关键反例

- “8号库位有什么库存？”不能只调用 `resolve_warehouses` 后结束；应继续查库存分布。
- “8号库位满了吗？”不能查库存分布代替容量；应查库位状态。
- “帮我出库”不能调用托盘查询并要求补托盘码；应识别为写操作并说明只读替代检查。
- “哪些产品没有质量标准？”是只读标准覆盖查询；“修改质量标准”仍是高风险写操作，必须拒绝。
- “哪些码打印了但没入库？”是二维码未入库查询；“帮我补入库”仍是写操作，必须拒绝。
- “作废码被扫描了吗？”在当前没有独立扫描日志时只能说明证据缺口，不能回答“没有发生”。
- “你能干嘛？”不能进入库存缺参兜底；应直接回答能力边界。

## 安全摘要

工具结果进入回答和 Review 时，只允许展示业务安全摘要，例如产品名、库位名、状态、数量、风险标签和候选数量。普通用户界面不得展示内部 ID、工具名、raw JSON、调用状态码、token、Authorization 或堆栈。
