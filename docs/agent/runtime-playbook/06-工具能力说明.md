# 06 工具能力说明

工具能力以 `docs/agent/tool-capability-registry.yaml` 和运行时代码中的 `TOOL_CAPABILITY_REGISTRY` 为准。本文提供业务侧使用说明，不替代工具 schema。

## 当前只读工具

| 工具 | 业务名称 | 适合回答 | 不适合回答 |
| --- | --- | --- | --- |
| `resolve_products` | 产品解析 | 用户输入产品名后确认候选产品或范围 | 直接回答库存数量；替用户选内部 ID |
| `resolve_warehouses` | 库位解析 | 解析“1号库位”“库位1”等自然语言库位 | 直接回答库存或容量；把数字当内部 ID |
| `get_inventory_overview` | 单产品库存概览 | 已确认产品当前库存、板件、总件数、重量摘要 | 全部产品、按库位聚合、写操作 |
| `get_inventory_distribution` | 库存分布查询 | 产品在哪些库位；某库位有什么；受控聚合分布 | 任意明细下钻、报表导出、库存修改 |
| `get_warehouse_status` | 库位状态查询 | 已确认库位的容量、占用、状态 | 某库位所有产品清单 |
| `get_pallet_status` | 托盘状态查询 | 明确托盘码的产品、位置、数量、化验、流转摘要 | 作废、恢复、确认任务、出库托盘 |
| `get_assay_status` | 化验状态查询 | 已确认产品和日期或明确化验记录的判定状态 | 批量趋势、导入、更新、删除化验、修改指标 |

## 常用链路

- 产品库存：`resolve_products -> get_inventory_overview`
- 产品库存分布：`resolve_products -> get_inventory_distribution`
- 库位库存内容：`resolve_warehouses -> get_inventory_distribution`
- 库位容量 / 状态：`resolve_warehouses -> get_warehouse_status`
- 托盘状态：`get_pallet_status`
- 化验状态：`resolve_products -> get_assay_status`，或上下文已有唯一产品时直接 `get_assay_status`

Resolver 只负责确认实体，不能作为最终答案。解析成功后应继续主查询；解析多候选时必须反问；未找到时不得编造。

## 关键反例

- “8号库位有什么库存？”不能只调用 `resolve_warehouses` 后结束；应继续查库存分布。
- “8号库位满了吗？”不能查库存分布代替容量；应查库位状态。
- “帮我出库”不能调用托盘查询并要求补托盘码；应识别为写操作并说明只读替代检查。
- “你能干嘛？”不能进入库存缺参兜底；应直接回答能力边界。

## 安全摘要

工具结果进入回答和 Review 时，只允许展示业务安全摘要，例如产品名、库位名、状态、数量、风险标签和候选数量。普通用户界面不得展示内部 ID、工具名、raw JSON、调用状态码、token、Authorization 或堆栈。
