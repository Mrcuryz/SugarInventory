## 1. 验收边界

本切片回答“某产品在一段时间内某个已登记化验指标的实测值如何分布和变化”，不是质量原因分析，也不在样本不足时输出改善、恶化或预测结论。

权威口径为：

- `assay.sample_date` 是生产日期，相对日期按北京时间解析；
- 支持色值、还原糖分、干燥失重、电导灰分、蔗糖分、不溶于水杂质和 pH 七项登记指标；
- 原始数值统计包含所有有该指标实测值的化验记录；
- 达标率只比较记录当时采用的历史标准中范围和单位均可比较的样本；
- 无历史标准、标准无法比较或单位不一致的样本不进入达标率分母，但不能从原始数值统计中删除；
- pH 等无量纲指标不显示伪造单位；
- 单次最多查询 366 天；31 天以内按日聚合，更长范围按月聚合；
- 核心统计由 Java 确定性计算，模型负责理解用户指标、选择登记报表并分析受控结果。

## 3. 验收中发现并修复的缺陷

| 缺陷 | 影响 | 修复 |
|---|---|---|
| 通用安全显示函数把空单位转换成“候选项” | pH 的均值、范围和标准后错误显示“候选项” | 指标单位改用可空安全文本；空单位统一序列化为空字符串，卡片不渲染后缀 |
| 单指标趋势卡片未进入公共折叠按钮条件 | 数据正确但用户不能收起长卡片 | 将 `quality_metric_trend_report` 纳入公共展开/收起条件和独立样式类，并用真实浏览器验证收起、展开 |

## 5. 体验与限制

真实模型路径完整呈现“理解用户需求 → 选择分析专家 → 专家决定登记报表 → 工具调用 → 结果分析”。本轮人工样本约 11～23 秒，仍不足以形成正式 P50/P95；后续必须从审计数据统计主模型、专家模型、工具和整轮耗时。

当前黄冰糖（袋）只有 3 条相关历史样本，数据足以验证统计口径和交互，不足以给出质量改善、恶化、原因或预测结论。模型和卡片均保持这一限制。

以下能力仍未完成：

- `ReportRun` 持久化、历史重开和跨会话复用；
- 基于同一 `ReportRun` 的导出；
- 跨期对比和指标波动排名；
- 库存趋势、生产消耗—产出趋势和流程效率；
- 订阅、主动触发、预测和任何写操作。
