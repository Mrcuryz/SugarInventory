## 已实现范围

- 默认生产汇总读取车间已保存的生产日报，包括草稿；订单登记产出保留独立口径，不混合、不回退冒充全厂产量。
- 概况使用完整范围合计，明细独立分页；支持多项指标追问。
- 日报分析按日展示数量与保存折吨，能耗保留原单位；缺日、空值、0及覆盖不足分开。
- 相邻前期和明确的等长非重叠自定义比较，各期最多31天；差额/比例由后端确定性计算，覆盖不足及零基期不输出误导增长率。
- 报表快照、历史和同快照XLSX；查看与导出权限分开。
- 今日整体运营组合以日报提供生产事实，库存、化验、任务仍用各自来源。组合当前仅今天/全部范围，没有整体归档或整体导出。
- 不新增预测、损耗定义或业务数据来源，不改日报填报流程。

## 本轮新增问题及修复

1. 软件入库操作帮助被误答为白砂糖工艺。根因是旧知识恢复逻辑将泛化“流程”强制归为工艺，覆盖了主模型判断。对明确软件操作/页面/按钮等请求不再强制知识恢复，主模型说明目前缺少已登记软件教程资料并询问具体环节；实际工艺问题仍走知识专家。没有新增软件帮助资料或凭模型记忆编造页面步骤。
2. 草稿口径校验漏掉“未提交行未计入合计”的同义表述。扩展既有矛盾校验，沿用一次有界重新分析，不再调用工具、不提高全局预算；分析专家明确草稿已在合计内。新增原句、同义句、正确否定句与真实工具循环单测。
3. 验收脚本仅检查卡片会漏掉以上错误。补软件帮助/工艺区分、草稿反向陈述和业务合计检查；仍人工复核完整回答。
4. 化验趋势7天完整序列在模型摘要中只有6条代表行，被模型误说成报表少一行。保留抽样预算，为每个抽样序列增加完整行数、展示行数、抽样标记及明确说明；未改变统计、卡片或导出。回归覆盖完整短序列、7天抽样和稀疏长序列。
