# 登记报表统一趋势图实施与验收记录

日期：2026-08-01
状态：通过
范围：六类登记报表的前端趋势图，不改变报表指标、数据来源或 Agent 工具权限。

## 1. 实施内容

- 新增统一 `RegisteredReportTrendChart`，复用已有 ECharts 依赖；
- 新增纯数据适配器，只读取业务卡片中已有的确定性报表字段，不在前端重新计算权威指标；
- 支持六类报表：
  - 生产登记产出重量；
  - 库存件数与库存重量；
  - 化验明确判定合格率与化验记录数；
  - 化验单指标均值与中位数；
  - 实际领料与稳定登记产出两条独立序列；
  - 托盘任务完成耗时中位数与 P90；
- 少于两个时间点时不绘制趋势，避免把单点伪装成趋势；
- 缺失值保留为空点，不转换为 0；
- 图表为补充视图，原指标卡片、逐日明细、数据质量和限制说明继续保留；
- ECharts 改为异步加载，不进入应用首屏主包。

## 3. 真实浏览器验收

账号：本地管理员测试账号。
输入：

```text
查询2026年7月14日至7月20日黄冰糖（袋）的库存变化趋势
```

通过历史报表打开本次不可变快照，核对结果：

- 期初 550 件 / 13,750 kg；
- 期末 790 件 / 19,750 kg；
- 净变化 +240 件 / +6,000 kg；
- 7 个时间点；
- 图表读取库存件数与库存重量两条序列；
- 页面继续显示“本地历史回放模拟”和生产门禁 0/7；
- 图表下面仍保留7天逐日明细和数据限制。

桌面宽度与 520px 窄屏均通过。验收中发现并修复：

1. ECharts 初始画布最小内容宽度会撑开窄屏卡片；通过允许图表容器收缩并限制溢出解决；
2. 热更新或隐藏容器切换时可能在 0 宽容器初始化；现在等待容器具有有效尺寸后再初始化，并由 `ResizeObserver` 补偿。

修复后浏览器没有新增 ECharts 初始化警告，卡片和页面 `scrollWidth` 与可用宽度一致。

## 4. 边界

- 图表不改变任何 ReportDefinition、ReportRun、FactEnvelope 或 CompletionEvaluator；
- 图表不推断增长原因、好坏、SLA、收率、损耗或预测；
- 库存历史回放仍只用于本地/UAT，不推进正式库存发布门禁；
- 当前没有实现综合经营简报、订阅、PDF/CSV 或预测。
