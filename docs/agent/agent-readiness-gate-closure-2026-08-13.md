## 3. 不能被技术线程代替的业务决定

1. 当前研发阶段没有真人参与，真人岗位验收延后到上线准备阶段；迁移不会静默修改任何现有账号。
2. 首个 L3 责任主体已确定为 `WAREHOUSE_MANAGER`，但权限严格收窄为受控成品入库，不含通用任务确认、出库、调拨、固定二维码启用或任务创建。
3. 若要收缩 `QC` 历史化验写入、任务处理和日志权限，应单独做权限治理评审；本轮不能借助手入口改造静默删除既有职责。

## 4. 推荐执行顺序

1. 研发阶段继续使用自动化账号和本地隔离数据库验收；真人只读、报表及仓管入库 UAT 延后到预生产阶段，不阻塞后续研发。
2. 按正式性能 SLO 补采首个进度、P90、分领域回归和最慢请求；在全天可运行的目标环境积累库存自然日终，并完成 RAG 外部材料与制品的可信交付验证。
3. 首个 L3 角色隔离自动化验收已闭环。进入生产前，仍需由业务/安全责任人只对受控成品入库作独立发布评审，不得自动推广到出库、调拨或其他写操作。
4. 上述生产门禁未闭环前，维持 `PRODUCTION_RELEASE_NO_GO`，不注册生产 MCP execute。
