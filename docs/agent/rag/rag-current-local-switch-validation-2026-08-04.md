## 3. 本轮发现并修复的问题

### 3.1 简短金属检测问法误路由

输入“白砂糖金属检测限值是什么？”时，RAG 已经 `READY`，但旧路由把它交给化验标准查询，返回无法解析产品。原因是确定性知识边界覆盖了“生产工艺/流程”等问法，却没有覆盖用户更常用的“产品 + 金属检测 + 限值”表达。

修复后，只有同时满足以下条件才进入 `PROCESS_KNOWLEDGE_QUERY`：

- 包含金属检测、金属控制或金属探测；
- 同时包含限值、阈值、参数、要求、标准或控制点。

显式产品名继续作为检索范围，普通化验标准、实时化验结果和库存问题不会因此改为知识查询。

### 3.2 本地服务认证配置不一致

首次重启 Python 后，Java 与 Python 的本地服务密钥不一致，访问日志为 401。成对重启并统一本地测试密钥后恢复。首次 Java 重启还使用了不足 512 位的 JWT 测试密钥，HS512 在登录时拒绝该密钥；改为 512 位 Base64 密钥后恢复。没有读取旧进程密钥、降低认证强度或把凭据写入仓库。
