## 实现内容

### 1. 会话到期与恢复

- 前端根据 `expiresAt` 和状态判断有效性；无时区的后端业务时间按北京时间解释，而非使用浏览器所在时区。
- 页面打开期间更新会话时钟；发送、回车、候选选择和卡片动作在执行前重新检查有效期。缺少或无法解析到期时间时不继续发送。
- 到期后显示明确提示和“开始新会话”，保留草稿；重新连接必须由用户明确点击，不自动重发旧问题或写操作。
- 新会话清除旧历史、待选项和确认弹窗；过期时关闭相关弹窗。时钟回拨不会自动恢复已经过期的会话。
- 本轮页面测试模拟的是客户端经过有效期，不是修改数据库期限，也不替代服务端鉴权。

文件：`webpage/src/components/AgentAssistant.vue`、`webpage/src/components/agent/agentSessionState.mjs` 及测试。

### 2. 错误分类与提示

- Python SSE 将结构化响应无效、模型拒绝/未配置等归为 `MODEL_ERROR`，不再误记为 `TOOL_ERROR`；Java 流式审计保留该分类。
- Review 遇到终态 error/timeout，或按 messageId 强关联的 runtime 失败时，记为 FAILED，而非因工具返回过数据就记为 COMPLETED。
- 时间窗口弱关联的其他轮失败不能覆盖当前成功回答。
- Java 通用错误提示改为“暂时无法完成本次查询……本次没有修改业务数据”，不再断言“未执行任何业务查询”；模型超时有独立中文提示。

文件：`agent-service/app/streaming.py`、Java `RuntimeRoutingAgentGatewayService`、`AgentMessageReviewServiceImpl` 及对应测试。

### 3. 模型诊断和无数据指令

- 结构化模型失败使用 warning 级别输出已有脱敏诊断，记录阶段、尝试次数、耗时、HTTP 状态、输入字节数和校验路径。不记录提示词、回答原文、校验输入值或认证信息。
- 旧指令“NO_DATA 后直接回答，不能再调用同一工具”与多主题目标存在冲突。改为不重复同参数查询；仍缺其他主题时允许由专家继续调用同一个工具，全部主题取得事实后再汇总。
- 没有增加重试次数或确定性关键词路由。下述复验显示该修正后两项均执行了查询，但最终分析仍超时，不能把指令冲突当作唯一根因。

文件：`agent-service/app/model.py` 及测试。
