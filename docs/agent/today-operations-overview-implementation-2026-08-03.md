## 2. 用户目标与事实范围

支持问题示例：

- 今天整体运营情况如何？
- 看一下今天的产出、化验、库存和待处理任务。

首版只支持 `Asia/Shanghai` 的今天，且开始、结束日期必须相同。原因不是技术偷懒，而是当前库存和当前待处理任务是生成时快照，数据库没有能够还原任意历史日全量状态的同口径快照。若允许历史日期，会把当前状态错误包装成历史事实。

报表只组合以下已存在事实：

1. 今日稳定登记产出：复用生产登记产出日报口径；
2. 今日已登记化验：复用化验判定趋势口径；
3. 今日确认领用与稳定登记产出：两条独立业务日期序列，继续禁止直接相除；
4. 当前库存水平：生成时全量当前在库库存聚合；
5. 今日创建托盘任务：按任务创建日期形成当日队列；
6. 当前待处理任务：生成时全量当前状态，明确不等同于今日创建任务。
