## 1. 验收边界

本次只验收只读的生产登记产出日报，不验收计划达成率、班次/产线、良率、损耗、预测、导出、订阅或任何写操作。

权威口径保持为：

- 按北京时间业务日期查询；
- 只统计生产订单中已登记且未取消的产出记录；
- 二维码需求、绑定和入库数量只作为后续流程进度，不计入产量；
- 单次报表最多查询 31 天，Agent 不得擅自缩短用户指定的范围；
- 核心数字由 Java/SQL 确定性聚合，模型只负责理解、选择登记报表和分析受控结果。

## 3. 验收中发现并修复的缺陷

| 缺陷 | 影响 | 修复 |
|---|---|---|
| Agent 会话只读 POST 白名单遗漏报表 Runner 路径 | 首次真实查询被权限边界拒绝 | 将 `/api/analytics/agent-read/reports/run` 加入受控只读 POST 白名单并补单测 |
| `dataAsOf` 展示微秒 | 卡片出现面向开发者的时间格式 | 前端统一裁剪时区和小数秒，只展示到秒 |
| 零产出日显示“未登记板件数量” | 用户可能误解为数据缺失 | 零产出记录固定显示 `0 板 0 件`；仅有产出但缺换算时才显示未登记 |
| 文本复述卡片全部字段 | 回答冗长、阅读负担大 | analytics 专家只概括 2～4 个结论、异常和口径边界，详细指标交给卡片 |
| 超过 31 天返回“AI 助手暂时不可用” | 把业务范围限制误报为系统故障 | Runtime 将该受控校验映射成用户可读提示；Prompt 同时要求不擅自缩短 |
| 模型改写产品名称并混淆板、散件、折算件 | 事实表达可能产生歧义 | 要求产品名逐字引用；明确三种数量字段的语义和禁止连写方式 |

## 5. 性能与未完成项

真实模型浏览器样本的完整回答约在 10～27 秒区间，进度状态能先于最终结果出现。这个样本量不足以声称达到 P50/P95 性能门槛，后续应由可重复的压测或审计时长统计给出结论。

以下能力仍未完成，不能因本次 PASS 被视为已实现：

- `ReportRun` 持久化、跨会话重开；
- 报表导出、跨期比较、订阅和主动触发；
- 化验质量趋势、库存趋势、投入产出趋势和流程效率；
- 计划达成率、良率、损耗、预测和写操作。
