## 2. 实测发现及修复

初次 API 的 O04 回答包含“如有车间已填报但未提交，也不会被计入”。这是错误业务口径，不能因为卡片数值通过就判为通过。失败原文保留在 `output/daily-report-overview/a-data-O04.json`。

修复仅限 Agent：

1. 生产专家明确所有已保存日报（包括草稿）均参与现有查询；不能套用订单产出排除草稿的规则。
2. 在现有模型完成校验中检查这类已知口径矛盾，送回已有的专家纠正流程；不通过关键词选择专家，不替模型调用工具，不改数值。
3. 增加 8 条允许/拒绝文案用例及 1 条专家纠正集成用例。后者确认只调用一次日报工具，模型在原有决策循环中纠正答案。

这是一项针对已观察错误的有限校验，不是完整的自然语言事实验证器，不能保证识别所有措辞变体。仍需要核对真实回答。
