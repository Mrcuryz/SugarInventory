# 化验录入口语交互修复与验收（2026-09-29）

## 范围与设计

承接 `agent-colloquial-demo-2026-09-28.md` 的三个未通过项：采样日期被猜测、包装限定未参与选择、自然语言保存意图指向失效卡片。本轮只修复本地 Agent 交互，不部署、不提交或推送，不新增库存/化验业务记录。沿用“模型理解 → 专家决策 → 工具调用 → 结果分析”，没有新增关键字执行分支，也没有给模型保存权限。

### 本轮规则

1. 专家结合上下文理解“记一下”“袋装那个”“酸碱度六点八”等表达；缺信息时只追问最关键的一两项，不要求用户重填模板。
2. `刚测完/今天测的` 不等于采样日期。预览参数增加用户事实校验；没有明确取样日期时交回专家追问。支持“昨天取的样”、采样问题后的“昨天”、明确日期及日期改口。模糊或冲突日期不自动选择。
3. 产品解析保留用户的袋装/箱装/桶装限定；支持“不是袋装，是箱装”的否定改口。化验录入候选只展示具有有效引用的具体产品，不把不可录入的大类混作可选项。
4. 中文数值与指标别名由专家理解；不确定的值与不明确的指标别名先确认。“其他没测”保持空值，不补零。
5. 修改单项时保留其他已确认输入。每轮新消息仍使旧预览失效；“就这样，帮我记上吧”必须重新预览并提供新的人工确认入口。
6. “算了，先别存”是停止本次待录入的对话控制，不是撤销已保存记录。由主模型选择现有直接答复动作，不再继续预览。
7. 预览只记录采样日期，结果说明不能擅自补上午/下午或具体时刻。文案尽量简短，避免重复整张指标卡片。
8. 结构化动作仍严格校验；格式重试补充静态动作字段约束，尤其是追问不能携带答案或观察引用。不将原始模型输出或业务敏感内容写入格式修复诊断。

这不是宣称覆盖所有口语。没有可靠解析的日期/单位/别名应追问；例如只说“周五”而未明确哪一周，可以要求确认具体日期，不能猜测后保存。
