# 化验组录入 D3c-1：人工页面及签名引用

日期：2026-09-24。范围：签名组引用、整组页面和结果恢复适配；未部署。

## 已实现与未完成

已完成：

- 组只读预览在人工保存开关启用时返回当前用户绑定的 `groupRef`；组引用与产品引用使用不同实体类型，不能互换，不能由另一用户复用。
- 新增人工接口 `POST /api/agent/sessions/{sessionId}/assay-entry/previews/from-group`。只接受签名组引用与检测值，不接受自行指定的成员、产品 ID 或未知字段；复用 D3b 服务端完整展开、存档与确认执行。
- 确认弹窗按产品/组引用选择对应人工预览接口，仍必须先展示服务端新预览。组确认说明明确“每个产品各新增一版、任一失败整组不保存”。
- 化验卡完整嵌套展示组内产品：各自版本、判定、参考标准、七项检测值及不合格原因。不显示原始 ID，不给子产品单独保存按钮，避免重复的子卡操作提示。
- 整组保存结果更新和刷新恢复不再要求顶层单条 assayId/version，而是验证所有成员的实际记录、版本、唯一性及数量。缺项、重复、部分成功、版本不一致均不能当作完成；保留待核实状态，阻止重新保存。
- 当前精确预览为整组时，单产品成功或减少成员数量的结果不能替代原组结果。

**尚未完成：模型侧真实化验组候选、组预览工具适配、组对话卡生成、HTTP/模型/浏览器端到端保存验收。** 当前仅具备页面承接能力，不能宣称用户已经能通过对话完成整组录入。工具登记数仍为 61 个 Goal / 56 个 Java 工具，人工接口仍不加入委托白名单。
