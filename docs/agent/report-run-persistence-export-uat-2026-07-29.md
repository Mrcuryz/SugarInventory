## 1. 验收边界

本切片为三个已登记报表增加最小 `ReportRun` 快照、历史读取和 XLSX 导出能力。报表生成后，页面、历史读取和导出都引用同一份不可变业务事实，不允许导出时重新查询并生成另一套数字。

本切片新增的是报表技术快照和导出审计记录，不修改库存、生产、化验、任务等业务数据，也不代表已进入 L3 写操作。

当前安全约束：

- `reportRunId` 为服务端生成的受控引用，客户端和模型不能自行构造内部数据库 ID；
- 每次历史读取和导出都重新校验当前用户、报表所需权限、30 天有效期和快照 SHA-256；
- 生产日报要求 `production:order:view`，两个化验报表要求 `assay:view`；
- XLSX 只从持久化快照生成，不重新运行报表；
- 每次导出生成独立 `auditRef`，记录导出人、时间、格式和导出文件 SHA-256；
- 内部枚举、数据库 ID、原始工具参数和模型思维链不进入导出文件。

## 3. XLSX 内容核验

对 `quality_metric_trend_v1` 的实际下载文件进行解析，确认包含：

- `报表说明`
- `核心指标`
- `指标序列`
- `产品分布`
- `历史标准`
- `数据质量`
- `数据质量提示`
- `口径与限制`

文件内保留 `reportRunId`、`auditRef`、快照 SHA-256、导出人和导出时间。pH 空单位保持为空，不显示“候选项”等错误业务词；核心指标为化验记录 2、实测样本 2、历史标准可比较样本 1、达标 1、超出 0。

## 4. 验收中发现并修复的缺陷

| 缺陷 | 影响 | 修复 |
|---|---|---|
| pH 有 2 个实测值但只有 1 个可比较历史标准时，模型可能把卡片中的 100% 错写成全部样本达标 | 自然语言与受控事实不一致 | 增加登记报表事实一致性兜底；分母缺失或模型过度概括时，使用确定性安全摘要 |
| pH 单位为空时被通用展示函数转换成“候选项” | 后端概念错误暴露给用户 | 单位字段改用空值安全文本，不再套用状态标签映射 |
| 单指标趋势卡片缺少展开/收起 | 长卡片影响对话浏览 | 纳入统一登记报表卡片折叠协议 |
| “化验质量趋势”可同时表示整体判定和单项指标 | 模型会增加一次澄清轮次 | 当前保持安全澄清；后续可在候选卡片中直接提供“看合格率趋势 / 看某项指标趋势”两个用户语言选项 |
