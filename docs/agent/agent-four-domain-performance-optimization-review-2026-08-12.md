## 3. 本轮实现

- 主路由明确返回 `goalType` 时锁定 GoalContract；专家初次请求只看到该合同 `allowedTools` 的交集。
- 参数绑定层增加同一 GoalContract 内的工具白名单校验，不能只依赖模型遵守提示。
- CompletionEvaluator 判定必需事实 `COMPLETE` 后，结果分析仍调用模型，但传入空工具集和专用短提示；只允许完整/部分回答并继续强制引用 observation。
- Runtime 拒绝完成态追加工具调用；候选发现、用户选择续跑、合法补证及重复调用拒绝等既有流程保持原行为。
- 增加安全数值诊断 `mainRouteInputBytes`、`expertInitialInputBytes`、`expertResultAnalysisInputBytes`。只保存编码后请求字节数，不保存 Prompt、问题、工具参数、工具结果或回答正文。
- 固定语料采样器同步聚合三阶段输入字节数。

为避免“自动推断的中间目标”误锁死合法多步流程，状态增加 `goal_contract_locked`：只有主路由明确登记目标才启用硬裁剪；工具事实反推的 Goal 仍用于完成判定和安全格式化，但不自动升级为新的模型规划边界。
