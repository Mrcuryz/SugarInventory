# 化验录入 D1：对话预览接入与验收

日期：2026-09-24。环境：本地隔离 Web 5180 → Java 38083 → Python 38092，本地数据库。未部署生产环境，未新增或修改业务化验记录。

结论：单产品对话预览的本轮主要场景通过本地验收。最终真实模型两轮12次请求结构检查通过，并逐条复核判定语义；后端12项HTTP复跑、浏览器候选选择及卡片检查通过。此结论不包含保存、化验组、真实权限撤销、单位歧义等后续扩展场景。

## 当前范围

日报阶段已完成本地验收，见[日报封板记录](production-daily-stage-closure-2026-09-24.md)。本轮继续化验录入 D1，只做单产品只读预览，不代表化验录入整体完成。

- 新增 `ASSAY_ENTRY_PREVIEW` Goal、`preview_assay_entry` L2工具，归属既有 `assay_expert`。当前61个Goal、56个Java工具（53个L1、3个L2），8个登记报表定义、2个组合配方不变。
- 沿用主模型识别意图 → 化验专家选择工具 → 真实产品解析/受控预览 → 模型分析。没有新增关键词直调工具分支。
- 产品必须由resolver或候选选择确定；模型只使用 `CURRENT_PRODUCT`，不能传猜测的产品ID。产品大类不是单产品录入对象。
- 预览接口：`POST /api/assay/entry/preview`；权限为 `assay:view AND (assay:create OR quality:test)`。会话只读委托精确允许该预览路径，仍拒绝现有导入、更新及任何执行路径。
- 原值、0、未填项分别保留；采样日期不默认今天；存储精度、已有版本、标准预判以现有后端为准。不因缺测擅自补0，不替用户舍入。
- 展示中文预览卡，明确“未保存”；当前没有保存按钮、执行凭据或化验执行工具。

## 本轮修复与发现

1. 对话真实调用曾被委托路径白名单拒绝，而直接登录调用预览正常。已补精确路径并测试导入/执行仍被403拒绝；业务权限门槛未降低。
2. Python权限拒绝码没有被Java映射为权限提示，导致通用重试提示。已补安全中文映射，不暴露原始异常。
3. 超精度输入被后端正确拒绝，但模型拿到通用工具错误。现在对三个化验预览业务错误给固定安全提示，不重复原参数重试、不泄漏异常。
4. 模型曾把“缺少检测值”解释成“未参与判定”。已约束分析忠实采用后端未通过原因。
5. “不能视为录入成功”等否定句曾触发保存成功误报。已补否定语境测试，同时继续拒绝“未保存，但已保存”等矛盾成功声明。
6. 模型经一次纠正仍无法给出合规结论时，仅在当前Goal完成、存在本轮成功预览证据和对应卡片的条件下保留服务端事实卡，用固定“尚未保存”提示替代错误总结。审计标记 `SAFE_ASSAY_PREVIEW_CARD_FALLBACK`，不冒充模型总结通过，也不通过此分支调用工具或写库。
7. 两轮结构断言通过后的人工语义复核，仍发现模型将旧判定文案“未命中任何标准”推断成没有配置标准、将缺测解释成未参与判定。适配层不再把该歧义句传给模型，保留真实判定标签、参考标准、全部未通过项目和缺测标记，明确缺测也是未通过原因；不修改后端判定规则。`assay-entry-agent-accepted-r1/r2`仅为结构通过记录，不作为最终语义验收证据。

完整输入/输出由 `scripts/verify-assay-entry-agent.ps1` 写入 `output/assay-entry-agent-*/`。失败记录保留，不以重跑覆盖。`StructuredCheck` 是结构断言，仍须结合文本和卡片复核。
