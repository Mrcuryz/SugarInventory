# 日报与今日运营来源对齐：C3实现记录

日期：2026-09-24。最新状态：C3本地真实链路验收通过，未部署；日报整体验收收尾中，化验写入尚未开始。最终真实模型有数据21/21、空日报3/3、三类权限角色及浏览器通过；Python637通过/5跳过、前端13通过。完整失败记录、修复、截图、清理及最终构建标识见[验收记录](production-daily-operations-acceptance-2026-09-24.md)。下方第4、5节保留初次离线实现时的结果与门禁，不代表当前仍未启动验收。

## 1. 本次实现

复用既有组合框架，新增固定配方 `today_daily_operations`，不是新增MCP工具或报表定义：

1. 主模型根据请求选择已登记配方。
2. 生产专家锁定 `PRODUCTION_DAILY_REPORT_RECORDS`，决定调用 `query_production_daily_reports`，再分析日报结果。
3. 分析专家锁定 `TODAY_OPERATIONS_OVERVIEW`，决定调用原运营报表；运行时只向本步骤分析和最终汇总提供化验、库存、任务字段。
4. 主模型根据两个步骤的权威观察组织综合回答，无工具权限；必须引用两个来源，失败项只能部分完成。汇总无效或模型失败时保留结果卡片并提供简短降级提示。

原生产订单查询、旧运营报表SQL/指标/历史与导出均未更改；没有数据库迁移、业务写入或新增权限。注册数量为60个Goal、55个Java工具、8个报表定义、2个组合配方。Java/Python握手同步新配方hash，工具和专家权限hash不变。

## 2. 范围与安全边界

- 当前配方仅今天、全部产品/车间。主模型对历史、指定产品/库位等综合范围应澄清或引导分项查询；运行时对可解析的历史日期另行拒绝执行今日查询。
- 每个专家使用独立状态和不可变执行身份，不继承旧产品、车间、分页或订单上下文。工具参数必须与当前步骤、当天日期及报表版本一致；不允许换成订单产出报表、跨期比较或暗加筛选。
- 两步共用既有最多3次工具预算，第二步不重置预算。没有扩大全局调用次数；没有关键词直接调用新配方工具。
- 原始运营响应先检验日期、定义/版本、必需字段和数值类型，再投影。缺字段/非法数值不由旧适配器默认成0。订单产出、领用、旧reportRunId不传到组合结果。
- 日报仍含已保存草稿；完整范围概况不是分页明细求和。空日报不切换订单数据；0、空值及缺记录保持区别。
- 日报和业务部分独立处理失败，认证失败立即停止；全部失败标记FAILED，不声称部分成功。原报表partial标记保守保留，即使提示来自已剔除的订单部分也不声称完整。
- 化验是当日已登记化验；当前库存不代表当日库存变化；今日创建任务和当前待处理任务是不同范围。
- 综合结果是临时分项展示，没有组合报表运行ID和导出按钮。日报正式分析及旧运营报告仍通过各自快照导出。

## 3. 现有权限限制（未绕过）

旧 `today_operations_overview_v1` 服务与归档均要求：

`production:order:view, production:material:view, assay:view, inventory:view, task:view`

日报另需 `production:daily-report:view`。此次没有因为剔除订单展示而放宽旧服务权限，也不自动给账号授权。缺少旧运营权限时，允许已成功的日报展示，运营项明确未完成。

代码依据：`RegisteredReportServiceImpl.run` 权限表达式、`RegisteredReportArchiveService` 定义权限映射。若后续希望只有部分领域权限的用户也看到各自业务分项，应独立设计分项工具组合，不能取消原报告权限。

## 4. 自动化用例

入口：`agent-service/tests/test_daily_operations.py`。模型使用可检查的结构化决策桩，不冒充真实模型验收。

| 输入/流程 | 预期及核验 |
|---|---|
| 今天整体运营情况如何？ | 主模型选择配方→生产模型调用日报→分析→分析专家调用运营→分析→主模型汇总；两次工具调用 |
| 日报200件/2吨，旧订单9999kg | 组合模型观察和卡片没有9999或订单产出字段，只保留日报作为生产来源 |
| 之前查昨天红糖车间第3页，再查今天整体运营 | 新步骤无旧过滤条件，重新固定今日全部范围 |
| 日报无记录，旧订单非空 | 日报观察保持NO_DATA，不回退订单来源 |
| 日报权限拒绝，运营成功 | 只保留可用业务部分，日报显示未完成，不声称无数据或0 |
| 两部分均权限拒绝 | FAILED及明确错误，不标记部分成功 |
| 首步认证失败 | 不继续调用第二个专家工具 |
| 日报或运营响应日期不同 | 拒绝错误日期证据，不渲染为成功 |
| 缺化验/库存/任务对象，计数null/布尔/负数/字符串/小数 | 拒绝，不默认成0 |
| 合格率为null / NaN / Infinity / 范围外 | null保留；非法值拒绝 |
| 修改步骤日期、过滤条件、分页、报表ID/版本、比较参数 | 参数范围拦截 |
| 总工具预算设为1 | 第二步不能获得新的预算，不执行第二次工具调用 |
| 汇总只引用一个分项 | 不接受完整汇总，降级保留卡片 |
| 配方恢复时篡改步骤工具 | 注册身份校验失败 |
