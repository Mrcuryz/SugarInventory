## 发现及修复

- 第三页实际12条，被回答为20条：适配器从实际行数生成 returnedRecordCount，专家区分每页上限与实际返回数。最终三页复测通过。
- 指标累计列错误显示“吨”：产品累计保留吨；指标改为“月累计填报值/年累计填报值”，不添加推断单位。Web测试增加保护。
- 模型逐行重复20条卡片，出现45～51秒服务不可用：专家最终回答限制为简短摘要，明细交由现有卡片展示；不提高全局超时，不减少可见数据。本轮最终请求6～13秒，但有外部模型波动，不能将速度变化完全归因于提示词，也不能声称超时根因已完全解决。
- 浏览器初测查单项指标却返回整个车间26行、文本擅加累计“%”：补强明确名称必须进入 itemQuery，以及指标当日单位不得传播到累计原值。HTTP最终轮F02已通过，浏览器复测另保留证据。
- 验收脚本增加卡片、total、实际条数、页码与hasMore断言；HTTP200但Agent不可用不再视为通过。文本语义仍须人工审核。
