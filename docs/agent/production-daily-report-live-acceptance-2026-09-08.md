- 现有本地影子配置只在进程内读取；核对数据库主机为127.0.0.1，没有连接生产服务器。

- 隔离端口：Web5174 → Java38082 → Python38091。RAG、本地库存趋势模拟、成品入库S2/S3执行均未开启。
- 未写生产日报、库存或现有账号；正常登录、会话、工具审计和登记报表快照属于本次验收产生的技术记录，不等于数据库完全零写入。

## 修复：运营记录时间不是全系统时间

Java运营概览组合限定日期的子报表和分页待办，latestRecordAt不覆盖全系统历史。因此不能向用户解释为“全系统最后一次业务登记时间”。

本次在Python `_adapt_today_operations_overview_report` 不再向模型暴露该局部时间，而返回明确范围说明；analytics_expert同时补充生成时间/记录时间边界。没有调整核心统计SQL，也没有为了得到全局时间增加无范围扫描或扩大专家权限。其余报表仍保留各自范围的记录时间。

新增确定性测试以2026-05-12局部记录时间与2026-09-08生成时间为输入，断言模型安全数据不包含该局部时间，且保留生成时间及范围说明。定向11通过；Python全量515通过、5跳过，wheel重建成功。Java/Web未因本次修复产生代码改动，沿用上一批各自测试结果。

本地工具审计（本轮开始后）：query_production_daily_reports成功5次，run_registered_report成功3次；与API对话及UI日报请求相符。普通用户响应toolCalls为空属于脱敏策略，不能据此判定未调用工具。
