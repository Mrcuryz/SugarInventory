# 标签打印助手管理员安装说明

## 1. 本次交付内容

本次先交付可运行的 Windows 图形化本地工具，包含：

1. 标签打印助手 GUI 程序
2. 本地 HTTP 服务，固定地址为 `127.0.0.1:9527`
3. 启动脚本 `start-printer-assistant-gui.bat`
4. 常见问题排查说明

## 2. 安装前准备

请在需要连接标签打印机的 Windows 电脑上完成以下准备：

1. 已安装目标打印机驱动，并能在 Windows 中正常打印测试页
2. 当前电脑允许本机程序监听 `127.0.0.1:9527`
3. 已安装 Java 21，或使用本次交付的 `app-image` 版本

## 3. 启动方式

交付目录建议使用：

```text
deliverables\printer-assistant\<时间戳>\
```

不要直接从 `target` 目录启动应用。

如果交付目录中包含 `LaibinPrinterAssistant` 文件夹：

1. 打开 `LaibinPrinterAssistant`
2. 双击其中的 `LaibinPrinterAssistant.exe`

如果交付目录中只有便携包：

1. 打开 `portable` 目录
2. 双击 `start-printer-assistant-gui.bat`

## 4. 首次配置

程序启动后，请完成以下操作：

1. 确认服务状态显示为“运行中”
2. 确认本地地址显示为 `127.0.0.1:9527`
3. 在打印机列表中选择现场实际使用的标签打印机
4. 点击保存默认打印机
5. 如需开机自动运行，勾选开机自启后再次保存
6. 点击测试打印，确认打印机能收到测试任务

## 5. 日常使用

1. Web 管理端会通过 `127.0.0.1:9527` 调用本地打印助手
2. 关闭主窗口时，程序默认最小化到系统托盘，不会立即退出
3. 当前系统托盘菜单为英文极简入口，仅保留 `Open` 和 `Exit`
4. 中文配置、测试打印、日志查看统一在主窗口 GUI 中完成
5. 如需完全退出，请在系统托盘图标右键后选择 `Exit`

## 6. 验收建议

建议甲方管理员完成以下检查：

1. `http://127.0.0.1:9527/health` 返回正常
2. `http://127.0.0.1:9527/printers` 能返回打印机列表
3. GUI 中能看到目标打印机
4. 默认打印机保存后，重启工具仍然生效
5. 测试打印按钮能正常提交任务
