# 固定产品二维码模式补充说明：打印并启用

## 背景

仅完成“批量绑定产品”和“仅打印”时，二维码仍处于静态准备状态，还没有正式进入本轮业务。

因此补充一个新的动作：

- 打印并启用

## 业务定义

“打印并启用”表示：

1. 当前二维码确实要投入使用
2. 二维码从 `FREE` 状态进入本轮业务
3. 复用现有入库任务链路，直接创建对应的入库任务
4. 后续可继续进入任务中心、入库确认、调拨、出库等流程

## 本次实现约束

- 仅允许对 `FREE` 状态的固定产品二维码执行“打印并启用”
- 一次“打印并启用”只能选择同一产品的二维码
- 产品名称由固定绑定关系决定，前端只展示，不允许修改
- 生产日期默认取当天，可在提交前调整
- 后端在同一条接口链路中完成：
  - 生成打印 PDF
  - 创建入库任务
  - 更新二维码到本轮业务状态

## 页面按钮口径

固定产品二维码池保留 3 个核心按钮：

- 批量绑定产品
- 打印并启用
- 仅打印

行内保留：

- 预览

## 打印字体

固定产品二维码标签的产品名称由后端渲染到 PDF 图片中。为避免 Linux/Docker 环境缺少 `Microsoft YaHei`、`SimHei`、`SimSun` 等中文字体导致产品名称乱码，项目内置 `src/main/resources/fonts/NotoSansSC-VF.ttf`。

渲染顺序：

1. 优先加载项目内置 `NotoSansSC-VF.ttf`
2. 加载失败时再回退系统字体
3. 托盘码编号仍使用默认英数字字体
