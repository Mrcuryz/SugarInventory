# 标签打印助手管理员安装说明

## 1. 安装前准备

请在需要连接标签打印机的 Windows 电脑上完成以下准备：

1. 已安装并能正常使用目标打印机驱动
2. 当前电脑可正常打印 Windows 测试页
3. 电脑已安装或允许安装本系统提供的 `setup.exe`

## 2. 安装步骤

1. 双击 `setup.exe`
2. 按安装向导完成安装
3. 安装完成后，从桌面图标或开始菜单启动“Label Printer Assistant（标签打印助手）”

## 3. 首次配置

打开程序后，请依次完成：

1. 确认服务状态显示为“运行中”
2. 确认本地地址显示为 `127.0.0.1:9527`
3. 在“默认打印机”中选择现场实际使用的标签打印机
4. 点击“保存默认打印机”
5. 如需电脑开机后自动运行，勾选“开机自动启动打印助手”并保存
6. 点击“复制连接密钥”，在 Web 管理端“打印助手设置”中粘贴并点击“连接助手”
7. 点击“测试打印”检查打印机是否收到任务

## 4. 日常使用说明

1. 本工具启动后会监听 `127.0.0.1:9527`
2. Web 管理端会通过 `127.0.0.1:9527` 调用本工具
3. 除 `/health` 外的本机接口都要求当前安装实例的连接密钥；密钥不会通过 HTTP 接口返回
4. Web 端只在当前浏览器会话保存连接密钥，关闭浏览器后需要重新连接
5. 关闭主窗口时，程序默认最小化到系统托盘，不会退出
6. 如需完全退出，请在系统托盘图标上右键选择“退出”

## 5. 验收建议

建议管理员完成以下检查：

1. `/health` 可访问且只返回最小在线状态
2. 不带连接密钥访问 `/printers` 返回 401，带正确密钥时返回打印机列表
3. GUI 中能看到目标打印机
4. 默认打印机保存后，重启工具仍然生效
5. 测试打印按钮可正常提交任务

连接密钥默认保存在：

```text
%USERPROFILE%\.laibin-printer-assistant\access-key.txt
```

该文件和 GUI 中的复制入口仅供当前 Windows 用户及现场管理员使用，不要发送到聊天、邮件或工单正文。
