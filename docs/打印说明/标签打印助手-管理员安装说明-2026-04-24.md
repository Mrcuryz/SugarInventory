# 标签打印助手管理员安装说明

## 1. 安装前准备

请在需要连接标签打印机的 Windows 电脑上完成以下准备：

1. 已安装并能正常使用目标打印机驱动
2. 当前电脑可正常打印 Windows 测试页
3. 电脑已安装或允许安装本系统提供的 `setup.exe`

## 2. 安装步骤

1. 双击 `setup.exe`
2. 按安装向导完成安装
3. 安装完成后，从桌面图标或开始菜单启动“Label Printer Assistant（标签打印助手）”

## 3. 首次配置

打开程序后，请依次完成：

1. 确认服务状态显示为“运行中”
2. 确认本地地址显示为 `127.0.0.1:9527`
3. 在“默认打印机”中选择现场实际使用的标签打印机
4. 点击“保存默认打印机”
5. 如需电脑开机后自动运行，勾选“开机自动启动打印助手”并保存
6. 点击“测试打印”检查打印机是否收到任务

## 4. 日常使用说明

1. 本工具启动后会监听 `127.0.0.1:9527`
2. Web 管理端会通过 `127.0.0.1:9527` 调用本工具
3. 关闭主窗口时，程序默认最小化到系统托盘，不会退出
4. 如需完全退出，请在系统托盘图标上右键选择“退出”

## 5. 验收建议

建议管理员完成以下检查：

1. `/health` 可访问
2. `/printers` 返回打印机列表
3. GUI 中能看到目标打印机
4. 默认打印机保存后，重启工具仍然生效
5. 测试打印按钮可正常提交任务
