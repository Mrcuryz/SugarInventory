# 标签打印助手常见问题排查

## 1. GUI 显示服务异常

请先检查：

1. 当前电脑是否已有其他程序占用 `9527`
2. 是否存在安全软件拦截本地服务启动
3. 是否使用了旧版本程序且未完全退出

建议处理：

1. 先退出旧版打印助手
2. 重新启动打印助手
3. 仍失败时，点击“查看日志”并将日志发给实施人员

## 2. Web 端提示未检测到标签打印助手

请检查：

1. 本机打印助手是否已经启动
2. GUI 是否显示“运行中”
3. 本地地址是否为 `127.0.0.1:9527`

## 3. 打印机列表为空

这通常说明 Windows 未识别可用打印机。

请检查：

1. 打印机驱动是否已安装
2. 打印机是否在线
3. Windows 控制面板中是否能看到目标打印机

## 4. 测试打印点击后失败

请检查：

1. 是否已正确选择默认打印机
2. 打印机是否缺纸、离线或报错
3. 目标打印机驱动是否支持当前 Windows 环境

## 5. 已保存默认打印机，但重启后丢失

请检查：

1. 当前 Windows 账号是否有写入用户目录权限
2. 安全软件是否阻止程序写入配置文件

配置文件默认位置：

```text
%USERPROFILE%\.laibin-printer-assistant\config.json
```

## 6. 看不到日志

日志默认位置：

```text
%USERPROFILE%\.laibin-printer-assistant\logs\printer-assistant.log
```

如果 GUI 中“打开日志目录”失败，请手动进入该目录查看。

## 7. 关闭窗口后程序似乎没有退出

这是预期行为。

默认关闭窗口只会缩小到系统托盘，方便 Web 端继续调用。

如需彻底退出：

1. 找到右下角系统托盘图标
2. 右键选择“退出”

## 8. 开机自启没有生效

请检查：

1. 是否使用安装包版本运行
2. 是否已勾选“开机自动启动打印助手”
3. 当前账号是否允许写入启动项

如果是开发环境直接运行 jar 或 IDE 启动，开机自启可能不可用或不稳定，建议使用安装版验证。
