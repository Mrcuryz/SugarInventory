# 标签打印助手 setup 打包后续步骤

## 当前结论

当前代码和 GUI 已可交付为：

1. `fat jar + 启动脚本`
2. `app-image`（如果本机 `jpackage` 可用）

当前机器如果要继续产出 `setup.exe`，还需要稳定的 Windows 安装包环境。对于 `jpackage --type exe`，通常需要 WiX Toolset，并且 `candle.exe`、`light.exe` 必须在 `PATH` 中。

## 推荐后续步骤

1. 在打包机上安装 JDK 21
2. 在打包机上安装 WiX Toolset，并确保 `candle.exe`、`light.exe` 在 `PATH`
3. 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-printer-assistant-setup.ps1 -Version 1.0.0 -PackageType exe
```

执行成功后，脚本会在控制台和 `delivery-summary.txt` 中明确输出：

1. `setup.exe built: True`
2. `setup.exe path: <实际 exe 路径>`

如果只看到 `setup.exe environment ready: True`，但 `setup.exe built: False`，说明只是环境具备基础条件，安装包并没有真正生成。

4. 如果打包机仍不稳定，先执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-printer-assistant-setup.ps1 -Version 1.0.0 -PackageType app-image
```

5. 将输出目录中的 `portable`、`docs`、`app-image` 一并交付给甲方管理员

## 固定已知路径

本项目当前仅使用以下固定工具路径，不再做全盘搜索：

1. `C:\Program Files\Java\jdk-21\bin\jpackage.exe`
2. `C:\Windows\System32\iexpress.exe`

## 交付建议

如果现场管理员需要先安装和验证打印链路，优先交付：

1. `app-image`
2. 管理员安装说明
3. 常见问题排查说明

待打印机实机验证通过后，再补发 `setup.exe` 安装包即可。
