# 标签打印助手第一阶段 Web 直连实施说明

## 1. 本次实现范围

本次已按《标签打印助手从 0 到 1 实施方案》完成第一阶段最小闭环：

1. 新增本地标签打印助手，监听 `127.0.0.1:9527`
2. Web 端新增“打印助手设置”
3. Web 端支持直接把标签提交给本机打印机
4. 打印助手不可用时，自动回退到原有 PDF 导出链路

当前没有改动原有二维码业务接口的核心语义，避免影响已有生成、绑定、启用、下载流程。

## 2. 本地打印助手

新增启动类：

- `src/main/java/com/Laibin/SugarInventory/printerassistant/PrinterAssistantApplication.java`

设计说明：

1. 独立于主业务应用启动
2. 不依赖数据库、Redis、Spring Security
3. 复用现有二维码与标签图片渲染能力
4. 默认只监听本机回环地址，不对外暴露

当前提供接口：

1. `GET /health`
2. `GET /printers`
3. `GET /config`
4. `POST /config/default-printer`
5. `POST /print/test`
6. `POST /print`

## 3. 标签渲染与打印方式

第一阶段仍采用固定模板图片打印：

1. 顶部显示标题
2. 中间显示二维码
3. 底部显示编码

当前模板尺寸固定为：

- `80mm x 60mm`

标签图片继续复用：

- `PalletQrLabelPdfRenderer.renderLabelImage(...)`

这样可以继续使用项目内置中文字体，避免 Linux、Docker、Windows 不同环境下的系统字体差异导致中文异常。

4. 保存本地默认打印机
5. 测试打印

## 6. 当前兜底策略

第一阶段采用“可用则直打，不可用则回退 PDF”：

1. 本地助手在线时，Web 直接调用 `http://127.0.0.1:9527/print`
2. 本地助手未启动、超时、打印机异常时，页面自动回退到原有 PDF 导出
3. `打印并启用` 仍保持“先业务、后打印”的顺序

这样可以避免因为打印助手未安装而阻断现场业务。

## 7.1 Maven 打包说明

当前已拆分为两个 Maven Profile：

1. 主系统默认使用 `main-app` profile，执行 `mvn clean install` 即可，产出 Spring Boot 可执行 jar
2. 打印助手使用 `printer-assistant` profile，执行 `mvn -Pprinter-assistant -DskipTests package`
3. 两个 profile 的打包插件完全独立：
   - `main-app` 只执行 `spring-boot-maven-plugin:repackage`
   - `printer-assistant` 只生成 `printer-assistant` classifier jar

这样可以避免主系统与打印助手两个启动类在 Spring Boot `repackage` 阶段冲突，也避免默认构建误产出普通薄 jar。

## 8. 当前限制

第一阶段仍有以下边界：

1. 仅支持固定模板 `fixed_product_qrcode`
2. 标签尺寸固定为 `80mm x 60mm`
3. 暂未接入 POSTEK 原生命令或厂商 SDK
4. `打印并启用` 的后端接口目前仍会生成 PDF，只是在直打成功时前端不再下载

## 10. 2026-08-12 安全边界补充

第一阶段原实现只从“绑定回环地址”理解本地安全边界，仍存在两个遗漏：

1. 主业务应用会扫描打印助手包，导致本机接口及打印助手的宽松 CORS 配置一并进入主服务；
2. 任意网页都可尝试调用本机打印、打印机枚举和默认打印机配置接口。

当前实现已调整为：

- 主业务应用完全排除 `printerassistant` 包，主服务不再暴露 `/health`、`/printers`、`/status`、`/config`、`/print` 等本机接口；
- 独立助手继续只监听 `127.0.0.1:9527`；
- 每台安装实例首次启动生成 256 位随机 Web 连接密钥，密钥只在本机文件和桌面 GUI 中可见，不通过 HTTP 返回；
- 除最小 `/health` 外，打印机枚举、状态、配置、测试打印和正式打印均要求 `X-Laibin-Printer-Key`；
- Web 端只把连接密钥保存在当前 `sessionStorage`，关闭浏览器会话后需要重新配对；
- 单次请求最多 100 个标签、200 个打印页，并限制模板、打印机名、编码和标题长度。

本机打印助手仍明确排除在服务端 Agent/MCP 工具集之外。
