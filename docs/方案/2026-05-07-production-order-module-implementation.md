# 生产管理一期实现说明

## 范围

本次新增轻量生产订单模块，不引入独立 MES 服务。生产订单负责串联：

- 实际领用半成品二维码
- 产出成品/半成品登记
- 固定产品二维码批量分配
- 后续托盘入库任务与入库进度

## 后端

新增表：

- `production_order`
- `production_order_material`
- `production_order_output`
- `production_order_output_code`

接口统一位于 `/api/production/orders` 下。生产订单默认创建为 `ISSUED`，订单号为 `POyyyyMMdd0001` 格式，订单号创建后不随生产日期变化。

半成品领用在同一事务内完成：锁定二维码和库存、校验在库半成品、写领用快照、写 `out_stock`、删除库存、更新库位容量、写 `ORDER_MATERIAL_PICK` 流转记录、释放二维码为 `FREE`。第一版不提供简单撤销。

产出贴码支持两类订单：

- 半成品生产订单产出半成品，创建 `SEMI_IN` 入库任务。
- 成品生产订单产出成品，创建 `FINISH_IN` 入库任务。

产出二维码从现有固定产品二维码池中分配，条件为当前产品、固定产品码、`FREE`、无当前轮次未完成任务，并使用 `FOR UPDATE` 加锁。

如果入库任务来自 `production_order_output_code`，托盘入库确认时后端使用该表保存的 `quantity/unit/pieces`，不信任前端传入数量；入库完成后同步产出码、产出行和订单状态。

## 前端

新增一级菜单“生产管理”：

- `/production/orders`：生产订单列表、新建订单、详情抽屉。
- `/production/material-pick`：Web 多选库存半成品二维码并确认领用。
- `/production/output-bind`：添加产出、展示拆分结果、批量分配固定产品二维码、查看二维码图片，并跳转对应入库任务处理页。

半成品领用确认前会提示：领用后库存移出、二维码释放，如需撤销需走人工退料或重新入库流程。

交互口径：

- 生产订单列表按成品生产订单、半成品生产订单分 Tab 展示，列表只保留订单号、生产信息、领用/产出摘要、创建人和操作，次要字段进入详情抽屉。
- 新建订单的计划领用、计划产出使用“产品 + 板数 + 件数”的结构化录入，不再使用自由文本。
- 订单详情顶部展示流程条。成品订单为“已下发 -> 已领料 -> 产出中 -> 待入库 -> 已完成”，半成品订单跳过领料步骤。
- 订单详情将计划领用与实际领用、计划产出与实际产出并列展示，用于现场对照。
- 生产订单列表根据订单状态突出下一步主操作，保留详情、删除等辅助操作。
- 订单列表中的计划/实际文案显式标注为“计划”“已领”“产出”，避免把计划领用误解为实际领用。
- 半成品领用页右侧拆为“已领用”和“已选待提交”两个表格，确认领用只针对待提交清单。
- 成品订单进入已领料、产出中、待入库或部分入库后仍允许补充领用半成品；补领不会把订单状态回退。
- 已下发且尚无领用/产出记录的生产订单允许删除。
- 产出未绑定二维码前允许修改或删除；绑定二维码后不允许修改或删除。
- 产出贴码页在待入库、部分入库阶段仍允许追加产出，并提示追加产出需要重新分配二维码并入库。
- 已完成二维码分配的产出行不再突出“分配二维码”；打印跳转固定产品二维码池并按本行二维码默认筛选，展示继续使用当前弹窗且不再标记打印时间。
- 产出二维码弹窗不展示任务 ID；每个二维码提供“查看”入口直接打开二维码图片。
- 产出行提供“去处理任务”入口：半成品产出跳转半成品入库任务页，成品产出跳转成品入库任务页，并按本行二维码默认筛选。
- 任务中心支持通过 `codes` 参数按多个二维码筛选，便于从生产贴码页直接定位当前待处理任务。

## 查询修复

- `production_order_material.row_number` 字段已存在于数据库中，但在 MySQL 8 中需要按标识符转义。
- 生产订单详情的实际领用半成品列表、半成品候选列表查询已使用反引号引用 `row_number`，避免触发 `ROW_NUMBER` 关键字语法错误。
- 生产订单领用半成品时使用 MyBatis-Plus 自动插入 `production_order_material`，实体字段映射也已改为反引号列名，避免插入快照时报同类语法错误。
- 新增迁移 `2026-05-07-add-order-material-pick-flow-type.sql`，将 `ORDER_MATERIAL_PICK` 加入 `pallet_flow_record.operation_type` 枚举，支持生产订单领用出库写流转记录。
- 产出行保存用户原始输入的 `X板Y件`，内部折算结果只用于计算二维码数量和单码数量，不再直接替代业务展示。
- 确认领用后订单状态自动推进为 `MATERIALED`，不再依赖前端手工“领料完成”按钮。
- 新增迁移 `2026-05-07-add-order-output-bind-flow-type.sql`，将 `ORDER_OUTPUT_BIND` 加入托盘流转枚举，支持生产订单产出贴码写流转记录。

## 备料池主入口清理

- 旧备料池后端接口和旧表暂时保留，用于兼容历史数据；新业务入口不再引导用户创建“转入备料池”任务。
- 半成品出库任务页移除“生产领用”Tab，只保留普通出库；生产领用统一进入生产管理的半成品领用页。
- 成品入库任务页移除“登记半成品用量”入口，成品与半成品追溯统一通过生产订单的材料和产出记录关联。
- 库存总览中的“备料池汇总”改为“生产中半成品”，数据来源改为 `production_order_material`，只展示未完成生产订单下已领用的半成品材料。
- 新增 `GET /api/production/orders/materials/in-process`，支持按产品、类型、筛网和生产日期查询生产中半成品，并可跳转生产订单页按订单号定位。
- 小程序库存查询同步将备料池页签改为生产中半成品，小程序扫码页移除旧生产领用模式。
