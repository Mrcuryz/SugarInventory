# 化验管理页改版说明

时间：2026-04-21

## 本次改动

化验管理页由原来的“大宽表”调整为“记录总览列表 + 右侧抽屉详情”结构：

- 列表区仅保留：产品名称、采样日期、化验员、是否合格、合格标准、操作。
- “操作”区提供：
  - 查看详细数据
  - 查看历史数据
  - 更多：编辑、复制、删除
- 详细数据抽屉统一展示：
  - 基础信息
  - 指标明细
  - 结论说明
- 历史数据抽屉改为“先选版本，再看详情”，默认优先查看最新版本的前一个版本。

## 交互原则

- 列表只负责找记录、看结论、进入详情。
- 具体指标值、标准范围、判定结果放到右侧抽屉。
- 历史版本不再在主表直接展开，避免页面横向拥挤。
- 保留新增、编辑、复制、删除等既有业务能力，不改变原有接口职责。

## 说明

- 本次改动主要发生在 Web 端 `Assay.vue` 页面组织层。
- 后端接口沿用现有详情与查询能力，未新增接口。
