# 小程序视觉重构实现记录

## 本轮范围

- 统一移动端视觉 token：主色、状态色、文本色、圆角、阴影、页面背景。
- 统一卡片、按钮、状态标签、分段 tab、空态、底部操作栏、弹层的基础视觉规则。
- 优化工作台、任务、扫码、查询、托盘详情、我的、帮助等新版主流程页面的卡片层级与交互质感。
- 补齐主流程与旧版存量弹窗的背景滚动锁定能力。

## 弹层滚动锁定规则

- 打开弹窗、确认框、底部操作面板时，通过 `page-meta` 设置页面 `overflow: hidden; height: 100vh;`。
- 遮罩层和弹层容器统一使用 `catchtouchmove="noop"` 或已有的 `preventTouchMove`，阻止触摸事件继续传到背景页面。
- 包含 `scroll-view` 的页面在弹层打开时按页面场景关闭背景滚动，避免用户拖动弹层时带动底层列表。

## 视觉规则

- 主操作按钮使用蓝色渐变与轻阴影；危险操作使用浅红体系，避免过度高饱和。
- 卡片统一使用浅边框、轻阴影、24rpx 以上圆角与渐变背景。
- 状态标签统一为圆角胶囊，按语义使用浅底色和语义文字色。
- 分段 tab 使用弱背景容器和高亮 active 项，减少普通按钮组的廉价感。
- 空态统一为带图形符号的提示卡片，并保留主操作入口。

## 后续建议

- 旧版管理页仍存在部分历史编码和文案问题，建议后续单独做文案与组件化整理。
- 如需支持弹层内部长表单滚动，应针对对应弹层增加内部 `scroll-view` 的滚动边界测试。
