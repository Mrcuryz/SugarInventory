# 演示环境脱敏

仅适用于 43.161.201.12 的 laibin-demo 项目及 laibin_demo 数据库。不得用于正式环境。

- Web 构建设置 VITE_DEMO_MODE=true，隐藏原公司名称和备案页脚；默认正式构建不变。
- 后端 DEMO_PRIVACY_ENABLED=true 使用中性日报标题及备注；导入兼容两种标题。
- scripts/build-demo-knowledge.py 独立编写演示知识，使用实际本地 embedding 模型建索引并执行 60 项评测。不读取或复制企业原始知识库。
- scripts/prepare-demo-privacy.py 只读本地数据库元数据，生成演示目标 SQL。替换产品名、公司名与人员字段，移除自由文本、内部检测数值及标准阈值；保留业务关系。
- 新 Redis 与导出卷隔离旧问答和导出文件。旧卷保留用于维护恢复，不能重新挂入公开演示服务。
- apply-demo-privacy.sh 校验目标地址、数据库及部署 JAR 校验和，备份后更新。备份在站点目录外，权限 700；不得作为恢复公开演示内容的常规方式。
- 对外截图只使用脱敏页面，不展示企业工艺、真实公司资料、密码或云平台控制台。

后续演示发布必须沿用演示知识库和脱敏数据，禁止重新使用最初的内部资料包。生产业务数据的数量仍来自测试快照，不可将其称为真实经营成绩或实施成效。

## 2026-09-08 验证结果

演示环境已完成切换并恢复。独立演示知识库的 60 项检索与权限评测通过；服务器运行时校验通过。实际页面展示演示产品名称，AI 库存查询返回演示货物及 8 个库位的分布。演示企业介绍查询返回虚构企业资料，原企业工艺查询未返回私有资料。

日报导出使用全新工作簿，避免模板的 sharedStrings 等内部 XML 残留。导出与导入测试通过，服务器实际下载文件的全部 XML 已扫描，未含原企业名称。

清理 SQL 仅针对 BASE TABLE，排除视图；字符串显式使用统一排序规则。失败时回滚事务，修正后重试成功。正式环境与本地源数据库未修改。
